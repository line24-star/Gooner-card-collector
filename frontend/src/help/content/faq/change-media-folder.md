---
title: How do I change my media folder?
category: Basics
order: 17
---
Open your **Player** page (the 👤 button in the top bar) and press **Change folder…**. That opens
the setup screen. While you have no cards, the setup screen is already what you see.

- **Choose folder…** opens the normal Windows folder window. Pick a folder and the app scans it
  right away. If the window doesn't appear, look for it on your taskbar.
- **Scan folder** scans the current folder again, for files you added since.
- **Type a path instead** lets you type the full path, such as `C:\Users\you\Pictures`, and press **Save**.
- **Open this folder** shows the current folder in your file manager, in front of the browser.
- **Use the default folder** goes back to the app's own `media` folder.

Good to know:
- If you already have cards, the app asks you to confirm. Cards from the old folder are **hidden**,
  not deleted. They return with their tags and coins if you switch back.
- The folder must exist, be readable and not be inside the app's own `data` or `profiles` folders.
- Your files are never changed. Your choice is remembered, even after a restart.
- Importing a newly chosen folder pays no coins, like your first import.
- If a saved folder isn't available at startup (for example its drive is unplugged), the app uses
  the default folder and tells you on the setup screen.

See [Adding media](#help:adding-media).
